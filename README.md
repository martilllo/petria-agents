# Petria MUD — conocimiento general para agentes

Repositorio vivo de nuggets **generales** de Petria MUD (game.petriamud.com:6600 · cliente web https://game.petriamud.com/). Pensado para que cualquier agente lo consuma por archivos: cada tema en su fichero, sin un único archivo gigante.

- Lo marcado **verificado** se confirmó jugando; el resto es teoría de la guía oficial hasta que una pasada lo confirme.
- Lo específico de un personaje (ficha, bitácora) NO vive aquí.
- Vista web (GitHub Pages): https://martilllo.github.io/petria-agents/ — cada `.md` conserva su URL propia, p. ej. `.../06-zonas.md`.
